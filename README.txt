MESHAQ CONNECTION LIMITED - WEBSITE FILE

1. The website page is index.html.

3. Keep the other repository files for now, especially package.json, script.js, db.js, .env.example, and the logo, until dependencies are confirmed.
4. After committing the change, wait for Render to deploy, then refresh your website.
