# MESHAQ CONNECTION LIMITED Website

A responsive, luxury-style static website starter for MESHAQ CONNECTION LIMITED.

## Files
- `index.html` — all website sections and forms
- `styles.css` — responsive design, navy/gold branding
- `script.js` — project gallery filters, WhatsApp enquiry builder, local demo comments and reactions
- `assets/meshaq-logo.png` — supplied company logo

## Run locally
Open `index.html` in a browser. For best results, run a local static server (for example, VS Code Live Server).

## Important production notes
1. **WhatsApp:** The project form prepares a message and opens WhatsApp at `https://wa.me/25471224050`. Confirm the number and country code before publishing.
2. **Phone line:** The provided number `0141 976710` is included as supplied. Confirm the correct Kenyan dialing format before launch.
3. **Email delivery:** This static website does not send email automatically. To receive submissions directly, connect a secure backend or form provider and configure email delivery.
4. **File upload:** File selection is only local in this demo. Attachments are not uploaded; the user is reminded to attach selected files manually in WhatsApp.
5. **Comments and likes:** Demo comments/reactions are saved in the visitor's browser only. For shared public comments, moderation, persistent likes and abuse protection, add a backend/database and moderation workflow.
6. **Gallery:** Images are illustrative design references, not verified MESHAQ CONNECTION LIMITED projects or necessarily Kenyan properties. Replace with company-owned/licensed images and verified captions before claiming completed work.
7. **NCA:** The page links to the official National Construction Authority website but does not claim the company is registered. Add verified company registration/licence information only after checking it.
8. **Maps:** The embedded map searches for Kondele, Kisumu generally. Replace with the exact office pin once available.
9. **Privacy/Terms:** The included copy is a starter template, not legal advice. Review and adapt it to the actual data handling and applicable Kenyan law before launch.
10. **External assets:** Google Fonts, Lucide icons, Unsplash images and Google Maps require internet access.
